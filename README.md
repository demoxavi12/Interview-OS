## 🚀 Interview OS

Interview OS is a personal command center for tracking interview preparation and coding practice.

### Features

- 📚 DSA progress tracking
- 🎯 Interview preparation dashboard
- 📈 Personal learning progress
- 💻 Clean, responsive user interface

### Tech Stack

- React
- TypeScript
- Vite
- CSS

### Getting Started

```bash
npm install
npm run dev
```

### Project Status

Currently under active development. More interview preparation tools and progress tracking features are planned.
